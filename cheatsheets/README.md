# Cheatsheets

Personal sheets for [`cheat`](https://github.com/cheat/cheat). `setup.sh dotfiles`
points cheat's config at this directory.

```bash
cheat -l          # list sheets
cheat nvim        # show one
cheat -e docker   # create or edit one
```

Sheets here: `nvim` (this repo's Neovim keymaps) and `python` (syntax reference).
A sheet is a plain text file named after the command that shows it.
